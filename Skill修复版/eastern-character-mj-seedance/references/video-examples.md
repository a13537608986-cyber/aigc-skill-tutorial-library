## 先判断首帧，再选动作

读清人数、眼睛开合、身体朝向、手指持物、遮挡、光向和空余空间。默认一条约4秒、单连续镜头、一个主动作；环境最多跟随两种轻微运动。构图和物件以实际图为准，文字草稿不能要求图片里不存在的马、茶杯、火苗重新出现。

| 实际首帧 | 宜延续的主动作 | 不自动追加 |
| --- | --- | --- |
| 草叶已在鼻前、眼睛闭合 | 一次轻微吸气或笑意加深 | 把草移到另一只手、转成正脸 |
| 手已扶杯、杯在桌上 | 轻抬杯沿后停住 | 换手、仰头饮尽、站起 |
| 符纸上缘已点燃 | 看向微动火沿 | 新燃烧法术、爆炸 |
| 骑者与静马同框 | 轻收缰绳或目光移向弯道 | 突然疾驰、增加路人 |
| 闭眼倚树 | 呼吸使肩部微起伏 | 强制睁眼、掀帽、起身拔剑 |

## V-R01｜草叶前的一次呼吸

前提：用户上传的单幅成图确实有闭眼侧脸、鼻前草叶和持草的手。以下根据已看截图的静态关系新编；不是对原视频动作的复述。

```text
约4秒单个连续镜头，继承输入图的竖幅侧脸构图与既有暖逆光。镜头固定。女子从首帧姿态开始轻轻吸气，鼻翼和肩部出现细微起伏，随后嘴角的笑意略微加深；眼睛继续闭合，草叶始终停在鼻前，手指握住原有茎部，不换手、不靠近到遮住面部。少量碎发和草叶尖顺同一阵微风轻动。保持脸型、发型、衣料颜色、指尖接触、背景层次和光向稳定。最后仍保留自然呼吸，不增加新道具、字幕或转场。
```

## V-R02｜杯沿轻抬

前提：实际成图中人物坐定、单手已扶杯、手肘有桌面支撑。全新动作设计，未生成测试。

```text
约4秒连续镜头，沿用输入图画幅、人物坐姿和桌椅位置。摄影机缓慢微推近，画面仍保留扶杯的手与桌沿。文士低头看杯，手指维持原有握持，将杯沿从首帧位置轻抬一小段，尚未碰到嘴唇便停住，目光跟随杯沿，肩部随呼吸微动。衣袖只在抬腕处形成自然褶皱，背景雾气缓慢漂移。人物、杯和桌面共享原光向，杯不变形、不换手、不突然出现茶水飞溅；全程不切镜，不新增另一只杯或同伴。
```

## V-R03｜火沿中的一次注视

前提：图中符纸上缘已经有小火苗，指尖明确夹住未燃部分。没有火苗的图不得直接套用此例。

```text
约4秒固定机位连续镜头，保持输入图人物与符纸的相对位置。术士的目光轻移到符纸已燃的上缘，下巴只作很小幅度调整，身体不转向。火苗沿已有燃烧区域轻轻摆动，纸缘逐渐卷曲少许，暖光在指节与脸颊上克制变化；手指始终捏住原有未燃部位，与火苗保持可见间隔。少量发丝顺同一风向轻动。保留原有冷暖关系、服装和纸片数量，不爆发法术、不整张燃尽、不增加烟幕或新镜头。
```

## V-R04｜静马上的轻收缰绳

前提：人物与马颈同框，缰绳两侧及持握关系在实际图中可辨认。

```text
约4秒单个连续镜头，承接输入图画幅与马背坐姿。摄影机保持固定，骑者先看向原画面内的道路方向，再轻轻收紧已有缰绳，双手各自沿原握持位置小幅回收，不交换缰绳。马颈只出现自然呼吸与轻微回应，马身保持原地，不起跑。发梢与衣缘随微风向同一侧摆动，光照与背景地形不变。保持人马比例、手指数量、马具与缰绳连通关系，不凭空增加鞍具、兵器或同行者，不切镜、不换景。
```

## V-R05｜倚树呼吸

前提：首帧人物闭眼，头部确实倚着树干；若无草叶，就不添加草叶动作。

```text
约4秒固定镜头，保留输入图头部与树干的支撑关系、帽檐阴影及原有裁切。游侠闭眼安静呼吸，胸肩出现一次轻微起伏，下颌随放松自然微动，头部不离开树干。只让原有鬓发与衣领边缘随微风轻摆，树影在脸侧缓慢移动少许，保持光源方向一致。若首帧已有嘴边草叶，草叶随呼吸微颤；没有则不添加。人物不睁眼、不掀帽、不起身拔剑，面孔、衣料和道具状态连续，结尾继续保留自然微动。
```

## 怎么改动作量

如果首帧手或道具被遮挡，优先改成目光、呼吸或轻微头部变化，避免要求模型补出完整复杂手势。遇到脸变形，先减少头部转动和镜头位移，不用“必须锁脸”代替设计修正。用户明确要5秒或其他时长时，以用户要求调整；本页不含模型调用参数，也不代表Seedance、MiniMax或第三方平台已运行验证。
