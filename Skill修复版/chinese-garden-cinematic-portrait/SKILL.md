# 中式园林人像 · MJV8.2

## 执行与输出

1. 判断任务为同风格创作、逐图倒推、局部修改或成图修正。读取 `references/prompt-baselines.md` 中对应基准；用户当前指令优先。
2. 未指定数量时输出一条完整英文提示词；指定数量则严格按数量输出。多图倒推按上传顺序逐张对应，不混合各图特征。
3. 每条正文70—90个英文词，参数另计；中文仅给简短标题和必要说明。每条放独立代码块，完整可复制，不写“同上”。用户要更短时优先保留景别、衣领、动作、空间关系及光线。
4. 默认16:9满幅电影构图。参考图指定的景别、人物大小和朝向优先；用户明确要求原图比例时沿用原比例。不要让横幅画面自动变成全身远景。
5. 只改场景时保留当前人物、发型、服装和已认可光色原文，仅替换场景；只改服装时保留其他部分。不同参考图不强行统一人物造型。
6. 默认生成提示词，不生成图片、视频或分镜。明确要求生图或视频时再使用对应工作流，不将其他工具生成结果声称为MJ成图。

## 核心视觉基准

- 将第二组六张园林电影截图及用户认可的六条提示词作为主基准。用户认可的是方案；未收到对应MJ成图，不声称已实测复刻。
- 默认单个年轻成年中国女性，柔和鹅蛋脸、自然头肩比例、温柔深色杏眼、自然眼白比例、低饱和桃色或玫瑰唇，神态安静而有注意力。避免夸张大眼、尖锐骨相、仰下巴和僵硬挺胸。
- 保持细微毛孔、轻薄粉妆、自然血色及柔和皮肤起伏；控制鼻梁、颧骨与锁骨高光，避免整脸油亮、蜡面和塑料质感。不要用堆叠“毛孔”替代光线修正。
- 默认黑色低盘髻、小型象牙白花簪与少量耳饰；保留参考中高盘髻、红发簪、金凤凰饰或自然面侧碎发。不要默认添加大型凤冠或排除所有碎发。
- 默认素象牙白无袖旗袍、小立领、贴合但不夸张的剪裁、真实丝绸细纹与自然褶皱。禁止自行改成露肩宫装、厚重金绣、西式礼服或乳胶。黑色花卉蕾丝品茗款保留不透明胸身内衬；仅在用户要求时换色或纹样。
- 为动作安排清楚落点：手低位自然相合、手扶栏杆、回眸、低头看花、托茶托并轻扶盖碗。保持肩颈放松，不默认复杂手势、提裙展示或高举道具。

## 园林空间与构图

- 建立真实中国私家园林的尺度和透视：太湖石、老松、枫树、浓密灌木、花木、曲廊、木格窗、粉墙黛瓦、水池及石径相互穿插。
- 每张选择一个主要空间关系：廊柱框住花庭；松枝从人物上方横展；太湖石围合人物；室内暗框包住窗外亮绿。不要把所有园林元素堆进一张图。
- 以前景少量枝叶、栏杆或石体形成遮挡，中景人物清楚，后景植物与建筑逐层退远。人像近景保留少量可读空间线索，环境人像保留园林结构，不把背景全部虚化成绿斑。
- 画面美感来自曲线与直线、明暗块面及人物大小的关系。允许深暗廊柱、横斜松干、大片植被与小面积素色衣服形成对照，不把每张都变成居中证件式美人照。
- 保持山石与道路可落足、栏杆连续、树干与枝叶连接自然。默认现实园林，不自动添加悬空宫阙、云海仙山、巨型荷叶或发光粒子。

## 光色：分别保留六类情境

| 场景 | 光线与明暗 | 构图特征 |
| --- | --- | --- |
| 格窗背影 | 窗外亮、室内暗，接近黑色人物剪影，轮廓微亮 | 背面中景、格窗秩序与近对称关系 |
| 花廊侧影 | 日照花庭、廊下柔和反射光，肤色自然微暖 | 侧脸朝花庭，深木门与斜栏框景 |
| 白花映面 | 面部广而柔的自然光，暗室衬亮窗和绿意 | 胸上人像，马蹄莲遮少量下身、不挡脸 |
| 松下回眸 | 树冠漫射光，冷绿环境衬微暖肤色 | 腰上转身，松针前景、叠石中后景 |
| 太湖叠石 | 柔和日光，灰石、深绿、少量锈红枫叶 | 较宽环境人像，人物偏低、斜松干与高石构图 |
| 暗室品茗 | 暖窗光照亮一侧脸和盖碗，暗侧保留柔和过渡 | 胸上低头，素墙光斑与深暗室内对照 |

- 不统一改成强烈夕阳、全白高调或平均柔光；剪影图不要强行补亮五官，暗室品茗不要自动消除阴影。
- 以50mm环境人像、85mm胸上人像、35mm园林空间作为创作镜头语言，不声称从图片鉴定了真实器材。保留细微颗粒与高光过渡，避免重磨皮、过锐HDR或游戏CG。

## 逐图倒推与修正

- 实际查看每张当前参考图，再提取景别、朝向、髻型、衣领、道具、光向与空间。读取失败时尝试可用附件路径；仍失败则说明并请重传，不凭文件名或旧记录声称看过新图。
- 忽略截图中的书法标题、英文署名、水印、播放器图标及黑边，重建满幅画面。不要抄入这些文字，不为了原文字区域预留排版空位。
- 区分观察与新增创作；用户只说还原时不擅自增加花、雾、珠宝或其他幻想元素。
- 油腻感：检查妆面、鼻颧高光、硬侧光、唇光和刻意姿势，优先减少过强光泽和雕塑感。
- 园林感不足：补一个可辨的空间关系及前后层次，不只是增加“Chinese garden”或“cinematic”。
- 过度写真感：恢复参考中的目光落点、环境遮挡和人物比例，不一律直视镜头、缩小到贴脸或强加笑容。
- 人物太小：保留环境结构，收回到指定腰上或胸上景别；环境图本就人物较小时不要擅自放大。
- 每轮只修改与反馈有关的部分，标明尚待成图验证，不承诺锁脸或精确复刻。
