# Skill 修复版使用说明

本合集含13个标准Skill目录。原始安装包另外保留；05、06、07、08、09原包缺少的11个文件（9参考、2脚本）由主文与教程重新整理或编写，并非找回作者原件。原参考图的逐图编号与对应关系未恢复。

## 使用

- 需要自动加载时，解压后选中所需的单个目录（目录内直接有SKILL.md），放入所用工具支持的skills目录。不要把含13个子目录的合集外层作为一个Skill安装。已存在同名Skill时先保存旧版。
- 只需要提示词时，可把相应目录中的SKILL.md及references文件夹交给Agent；让它先读主文，再读取任务需要的参考文件。仅上传SKILL.md会遗漏新补参考和脚本。
- 05与06脚本只需Python 3标准库。先用 python3 <Skill目录>/scripts/check_prompts.py --help 或 check_mj_prompts.py --help 查看选项，再传入提示词草稿Markdown。英文提示词一条一个text代码块；默认10条、每条50–80词，参数计入。脚本通过不代表出图效果通过。
- 04完整图片及视频生成依赖豆包原生能力。19/21建画布依赖已授权LibTV调用能力；可通过Remote MCP或本地CLI，Remote MCP不要求安装本地CLI。纯文字候选或资产拆解可先完成。

## 本次验证范围

检查了13份标准入口和本地文件引用，运行了两个脚本的正反用例，并逐份完成实际文字任务。没有运行付费生图/视频，也没有把文字方案当作真实画布或成片。测试结果、改动记录与原包SHA在Skill修复与测试.json中。
