## 先选变化机制

每轮交锋至少改变距离、朝向、支撑、路线、可用资源或主动权之一。先问双方想完成什么，再选以下一种主要机制；不要把八种题材的重音一齐塞进一条30秒片段。

| 题材 | 适合的状态变化 | 镜头与反馈 | 常见混乱 |
| --- | --- | --- | --- |
| 写实武侠 | 远距离封路→被迫换线→借地形脱离 | 中景看脚步与兵器关系，保留呼吸和地面摩擦 | 无支撑起飞、空手无代价挡刃、伤势自动消失 |
| 仙侠 | 先建立一种能力规则→改变同一空间中的可达路线→能力退去后仍有后果 | 特效从已有武器触发，保留身体和接触点 | 临时增加瞬移、能量只增大不改变战术 |
| 徒手对抗 | 接近→可见躲避或受力→重心改变→重新拉开 | 中近景与全景交替，碰撞后身体有位移 | 原地摆拳、连续无反应、镜头抖动代替接触 |
| 长短兵器 | 开阔处长兵器封路→狭窄处回收受限→重建距离 | 看清兵器长度、回收和空间边界 | 长枪穿柱、剑忽长忽短、手同时抓两个物件 |
| 机甲 | 承压→部件负荷变化→姿态与路线调整 | 低位观察重量，金属受力与地面反馈延续 | 机器无惯性、结构瞬间复原、人类轻盈连招套壳 |
| 怪兽 | 大体量接近→建筑/地表反馈→小体量一方改变路径 | 用固定地标保持尺度，局部近景后接回全景 | 每镜换尺寸、地形消失、尾巴穿过建筑无后果 |
| 追逐 | 目标与退路建立→障碍迫使双方改变速度/路线→明确是否脱离 | 保持运动方向，用前景与距离体现速度 | 拐弯后换街区、追者无原因忽远忽近 |
| 群战 | 局部两人冲突→另一人从可见通路切入→焦点转移 | 交代场外人在绕行、受阻或准备进入 | 其他人站等、所有人同时挤进同一接触点 |

## 四种可复用动作链

这些是叙事结构，落实时必须把人物与地形换成用户已有资产。

### A｜封路与换线

B占据主通道，A无法直接通过 → A沿已有障碍边缘移动 → B为保持封路回收武器并转向 → A趁这次方向变化进入另一段可见通道。结果是距离与路线改变，不是A突然变快或穿过B。

### B｜压力与脱困

A在首帧已处于受压或退让状态 → 已建立的支撑面允许A稳住身体 → A调整方向离开原来的直线 → B的推进延续到新的接触位置，双方重新建立距离。稳住的支点先在画面里出现，不借不存在的柱、半空碎片或刚刚远离的屋檐。

### C｜地形让优势翻转

开阔处B的长兵器容易组织画面，A需要绕行 → 双方通过同一入口进入狭窄回廊 → B必须回收和转向，A获得移动窗口 → 再回到开阔处时B可重新拉开距离。三种地形变化要有实际通路，不能只用场景名替换。

### D｜消耗与新选择

A此前的防守使装备或支撑环境发生可见变化 → 这个变化限制其下一步 → A选择较短路线或更小动作 → 结果保留损坏，改变后续重心与资源。不要用闪光让损坏复原，也不要为了升级凭空获得新能力。

## 题材重音怎么落地

- **写实的快**：人物确实从一个地标移向另一个地标，近处背景掠过；对手有原因地转身或退让。不是摄影机自己绕着原地人物转。
- **仙侠的强**：能力改变退路、视线或空间压力，并有来源、方向和退去过程。效果不能遮到看不见兵器归属。
- **机甲的重**：动作启动先有支撑姿态，停止后有余动，地面和金属反馈跟随同一受力方向。选一个主要部件反馈，不自动拆解整机。
- **怪兽的尺度**：正常建筑、道路或桥梁持续存在。先固定体量参照，再允许局部近景，不在下一镜把街区变成桌面模型。
- **群战的清楚**：同一时刻让一组主要关系可读，其他角色的位置和进入意图仍被交代；先后加入不是全员排队等待。

## 新编30秒示范｜穿过柱廊脱离封路

创作设定：30秒、16:9、写实武侠；A为成年女剑客，右手始终持一把出鞘长剑，目标是从石院进入右侧门洞；B为成年男枪客，双手持一根长枪，目标是阻止A经过。只有两人，同一层地面，右侧柱廊与门洞从开场即存在。无新增法术。以下仅为新写提示词，未生成验证。

```text
【片段】30秒，16:9横版，写实武侠连续空间。冲突围绕“女剑客要进入右侧门洞，男枪客封住路线”展开，结束于是否成功脱离；无对白，不增加第三人。
【角色与空间】女剑客着深青短外衣，右手持出鞘长剑，空鞘固定左腰；男枪客着暗红衣，双手持完整长枪。石院中央开阔，画面右侧是一段可通行柱廊，尽头为门洞；所有区域位于同一层地面。兵器归属、服装和门洞位置全程不变。
【动作时间轴】
0—4秒：侧向中全景建立双方、右侧石柱与门洞。男枪客沿院中前进并横向封住通路，女剑客向右侧柱廊退让，脚步连续，不突然移到对手背后。石板摩擦与衣料声建立节奏。
4—8秒：女剑客在第一根石柱前改变行进方向，沿柱侧靠向柱廊。男枪客为继续封路转身并先回收长枪，枪杆不得穿过石柱。摄影机同向横移，保留两人的距离与柱边界。
8—12秒：男枪客从柱外绕过，重新面向女剑客；女剑客沿柱廊退向门洞。女剑客用持剑一侧的姿态维持与枪杆的可见间隔，没有另一只手凭空持新兵器。镜头保持中景，观众看清角色朝向。
12—16秒：男枪客试图在柱廊内重新展开长枪，但墙与柱迫使他缩短握持范围并调整站位；女剑客停住直退，沿已经露出的柱间通路侧移。衣料随转向回摆，先前脚步方向自然改变，不发生腾空换层。
16—20秒：摄影机移到能同时看清门洞和双方的中性位置。女剑客继续从石柱另一侧朝门洞移动，男枪客沿外侧开阔线跟随，双方围绕同一根柱形成可见的路线差。没有剪切瞬移，背景柱序与门洞位置连续。
20—24秒：男枪客在开阔侧重新放长握距，逼近门前通路；女剑客不得直穿长枪，而是在原有运动方向上短暂停步，再利用柱体遮挡的可见间隔接近门边。镜头固定偏侧全景，让观众看清最后距离变化；配乐压低，保留短促呼吸与脚步。
24—27秒：女剑客沿已建立的门侧通路进入门洞，剑仍在右手，身形没有穿透门框；男枪客回收枪身转向门口，动作持续可见。门框成为自然前景遮挡，切镜只在方向已经清楚后发生。
27—30秒：门内侧中景，女剑客在门框后停稳呼吸，右手持剑保持完整。镜头稍向外侧露出院中仍持长枪的男枪客，二者被门框清楚分隔，女剑客本段脱离成功。保留场景、武器与人物状态，结尾不黑场遮挡，不以白光代替结果。
【连续性与视听】速度来自连续步法与路线变化。主要观察机位跟随同一侧运动，必要的方位切换先用中性机位重建。衣料、呼吸、石板摩擦与兵器动作的拟音各有主次；不为重音增加未发生的碰撞、伤口或破坏。摄影机不同时环绕、升降与变焦。
```

示范可以迁移为仙侠，但应先由用户或角色设定给出能力，再用该能力改变同一条空间路线；不要仅在每段末尾追加粒子爆炸。

## 避免重复套路

如果上一条已用“屋顶追逐—穿墙—光球对撞”，下一条优先换战斗目标、地形限制或优势来源，例如争取通过门洞、保护已有物件、从狭窄地形脱离。保持用户指定的角色与风格，不能为了变化擅自更换结局。先选一条最适合的动作语法，最终只输出用户要的一版完整提示词。
