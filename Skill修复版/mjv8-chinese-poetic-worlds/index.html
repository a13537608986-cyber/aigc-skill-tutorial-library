# MJV8 中式诗意巨物美学

先把用户的简短想法扩写为独立可复制的英文图片提示词；用户生成图片并上传后，再依据实际成图输出约 4 秒的中文图生视频动态提示词。用中文给标题和必要说明。两个阶段都默认只交付提示词，不调用生成服务、不代用户消耗生成额度。

本 Skill 把一组九张参考图的可见规律整理成创作规则，并未训练 Midjourney，也不保证像素级复刻。原九图的完整逐图描述未能追回；[修复版风格档案](references/style-atlas.md)依据原主文和可核对的教程截图重新整理，不声称恢复九图原件。无需依赖旧对话即可使用。

## 两阶段工作流

| 当前输入与意图 | 执行阶段 |
| --- | --- |
| 一句话、新题材，或明确要分析新参考图并出生图提示词 | 图片阶段：按下文风格、构图与 MJV8 参数生成英文提示词。 |
| 同一工作流中上传已经生成的图片，或说“图片生成好了”“让这张图动起来”“出4秒动态提示词” | 视频阶段：实际看图，读取 [references/image-to-video.md](references/image-to-video.md)，每张图给一个约 4 秒的独立中文动态提示词。 |
| 明确要求图片提示词和动态提示词一起出，但尚无实际成图 | 先交付 MJV8 图片提示词；动态部分可按画面设计预写，但标明“待成图校正”，不要声称已按成图分析。拿到成图后再校正动作。 |

默认端到端工作流是：用户只给主题或参考图、尚未提供成图，且没有明确说“只要视频”时，先输出 MJV8 图片提示词；用户生成并上传成图后，再输出每张约 4 秒、默认按 Seedance 2.5 兼容写法组织的中文动态提示词。用户说“只要图片”时只输出图片阶段；用户说“只要视频”或已经提供生成好的图片时跳过图片阶段。视频阶段不要重复输出生图提示词。上传多图时按图片顺序一一对应；多张图各自约 4 秒，不自动拼成一段长视频。用户明确更改时长、语言、镜头数量或视频模型时服从其要求。

## 图片阶段：先确定用户要什么

提取题材、数量、画幅、人物要求、主要动作、构图偏好和模型版本。已有信息够用时直接输出，不先发问卷。

- 数量明确时严格按数量输出；未指定时，单个明确画面出 1 条，“一组／几张”出 6 条。这是默认值，服从用户覆盖。
- 图片阶段画幅未指定时默认 16:9；竖屏壁纸用 9:16，人像或封面可用 3:4。用户指定画幅优先。视频阶段默认继承上传成图的画幅与裁切。
- 只有场景要求时不要强加人物；纯景可用舟、桥、民居作尺度参照。只要人物半身时就保留半身，不为了巨物把人强行缩成远景。
- 连续人物系列先提炼简短人物锚点：成年、外貌特征、发型、服装主色与轮廓，在每条提示词中重复这些必要词。默认可用自然东方五官、黑色长发半束、轻薄传统汉服；人数、性别、长短发均服从当前用户要求。
- 用户只给本风格名称而未给题材时，采用“巨荷水乡里的夏日闲游”。用户换成银杏、竹林、紫藤等题材时，迁移尺度、光色与生活关系，不继续硬塞莲花。
- “MJV8”按 V8 系列理解。版本、参数与参考图接法遵循下方“图片模型与参数”，不要把过期写法混入成品。

## 固定风格骨架

将以下关系融入所需画面，而非逐条堆成标签。核心定位：**以真实摄影观感呈现可居、可游的中式超现实自然世界。**

| 维度 | 写进画面的具体特征 |
| --- | --- |
| 世界设定 | 把一种自然物放大到空间尺度：荷叶可作亭盖，花朵像山体，植物冠层覆盖街巷。自然物的形态仍有植物结构。 |
| 尺度证据 | 用人、舟、瓦房、桥等熟悉物明确对比，如“单片叶子遮住整个庭院”“正常大小的木舟从粗壮叶柄之间通过”。不要只写 giant。 |
| 人物关系 | 人在世界里生活：乘凉、倒茶、垂钓、撑舟、回望、赏花。表情松弛，身体有落点，道具有人与物之间的接触。 |
| 主色 | 青绿／灰绿／墨绿为自然底色，天青或水蓝拓开空间，米白／藕粉／浅杏点亮服饰和花瓣。保持清新色相与适度饱和，不整体去色。 |
| 光线 | 明确来自太阳或天空的自然光；侧逆光透过薄花瓣、叶缘和纱袖；叶下保留有细节的深色阴影，水面可提供轻微反射补光。 |
| 材质 | 叶脉有厚薄，叶面有自然蜡质反光；花瓣有柔韧褶皱与细纹；衣料有织纹、层叠与重量；水面有涟漪、反射或可见水下细节。 |
| 空间 | 用前景遮挡、中景活动、后景环境建立层次。叶片弧线、桥洞、船舷、钓竿或水道组织视线；为天空、水面或单片叶面保留视觉停顿。 |
| 气质 | 轻盈、温润、悠然，奇观与生活并存；镜头感自然，人物与环境共享光向、色温、阴影和透视。 |

参考图中植物尺度违反现实，这是奇幻设定；皮肤、衣料、水、接触阴影和照明仍需可信。巨物不是雕塑、纸花或塑料布。不要把人物整体同比缩小成微缩模型、Q 版或玩偶。

新主题可以改变季节、色彩和活动；保留“自然成为空间”“可信物理质感”“有温度的生活关系”。用户明确要求其他画风时按要求调整，不让默认规则覆盖任务。

## 构图与场景编排

每张先选一个视觉主意，再写提示词。一个画面通常只需一种主导奇观、一个主要活动；复杂群像可给每人一个清楚的分工。

从下列构图中按需选择。多张系列变换机位、景别或人与环境关系，不能只换花色与形容词。

| 构图 | 适合画面 | 保真重点 |
| --- | --- | --- |
| 水面低机位 | 小舟穿行、仰看荷叶冠层 | 船舷导向主体，水波有尺度，叶柄从水中生长。 |
| 斜俯视 | 叶上垂钓、清水池塘 | 人物落在叶面上，叶片与水有高差，钓线或钓竿引向涟漪。 |
| 中景生活群像 | 叶下喝茶、乘凉、吃瓜 | 给人安排座位和手部动作，器皿立在可承托的台面上。 |
| 环境人像 | 舟上或花前的半身、全身肖像 | 写准用户的裁切要求；巨物以跨越画面的花瓣或叶脉体现尺度，不抢掉人物。 |
| 框景远景 | 桥洞内的巨莲、窗外奇景 | 明确前方框架、中间空间、后方主体，花不长在桥上。 |
| 高处眺望 | 屋顶人物、古镇与植物天幕 | 瓦房保持正常尺度，叶冠跨越多条街，远景空气透视渐弱。 |

镜头词按画面选择即可：24–35mm 适合环境与尺度；50mm 适合自然环境人像；更长焦仅用于用户需要的压缩或肖像。可不用焦距，不要同时塞多个镜头参数。

图片阶段默认取全画幅画面，不复刻截图的黑边、水印或字幕。图片提示词只描述一张静态图的可见瞬间；“举竿时鱼跃出水面”可以，“先钓鱼再起身转镜到古镇”不可以。视频阶段按下方动态规则处理时间变化。

## 编写英文提示词

使用自然、具体的英文短句，推荐顺序：

**景别／机位 → 主体与动作 → 环境及尺度证据 → 构图关系 → 光色 → 2–4 个材质证据 → 整体摄影观感 → 参数**。

- 优先控制在约 70–120 个英文词；用户要求精简时约 40–70 词。复杂指定细节可超过建议长度，但不能为凑字数删掉人物设定或关键空间关系。
- 尺度与动作放在靠前位置；每条独立包含风格与人物必要信息，不写“同上”“沿用图一”，不要求用户拼接通用前缀。
- 用 `photoreal cinematic still`、`natural skin texture`、`soft highlight roll-off` 等与可见效果直接相关的词即可。不要堆相机、胶片、渲染器、8K、杰作等同义质量标签。
- 适度柔和不等于失焦。远景和人物小景别不强求毛孔；人物近景保留自然肌肤微纹理，但不夸大粗糙、油光或锐化。
- 不用 `tiny woman` 指代正常成年人。优先写 `a normal-sized adult woman dwarfed by...`，或用建筑、船与植物的空间关系表达尺度。
- 大远景通常保留可读的环境深度；不要同时要求“极浅景深”和“远近全部清楚”。水面镜面反射与水下透视按机位选择，不要求每处同时极强。
- 不声称识别出原图真实使用的相机、模型或渲染器。需要器材词时，注明它是创作选择而非原图事实。

## 图片模型与参数

输出前按需阅读 [references/mj-parameters.md](references/mj-parameters.md)。其中记录修复版的官方核对日期、V8 系列兼容性和参数依据；涉及最新可用版本或未收录功能时核对官方文档。

当前兼容基线（2026-09-11）：官方 V8.0 已停用，V8.2 可用。“MJV8”泛指系列时使用 `--v 8.2`，首次用一句中文说明。用户明确指定 V8.1 时保留 `--v 8.1`；明确要求已停用的 V8.0 时说明限制并交付提示词正文，不把 `--v 8` 标为可执行参数，也不声称完成了 V8.0 生成。

本风格的起始后缀：

```text
--ar 16:9 --v 8.2 --raw --s 100 --no text, watermark, logo, anime, cartoon
```

按用户画幅修改 `--ar`。`--s 100` 是起点，50–100 可用于更强的内容约束，150–250 可探索更装饰的观感；这些是待试出的创作建议，不是已验证的复刻配方。用户希望文字、动漫或特定标识时相应删掉排除词。

参数集中在正文末尾，不加 `--q`、`--cref`、`--oref` 或正文多重权重 `::`。不要自动添加随机风格代码、个人风格配置、HD 或高混乱度设置。负向参数保持短小，优先排除独立名词；用正面材质描述解决塑料感，不把 `--no plastic skin` 这类词组误作精确语义约束。

### 图片阶段有参考图时

1. 先实际看图，再提取与本风格匹配或需要覆盖的特征。打不开时直说，不编造图像内容；若用户只需已有风格提示词，可继续用本 Skill 的风格档案。
2. 需要保持画风时，将 1–3 张风格一致、最相关的图用于 Midjourney 的 Style Reference；不要认为九张全塞入就一定更准。可提示用户预先避开截图黑边和水印。
3. 网页端可将图片放入 Style Reference 区；已有实际可访问图片 URL 时可添加 `--sref URL --sw 100`。没有 URL 时只给网页端一句操作说明和完整纯文本提示词，不把本地路径、附件 ID、虚构 URL 或占位符放入可复制代码块。
4. Style Reference 侧重色彩、材质、光感，不锁定具体人物身份或精确构图。人物连续性可用固定描述增强，但不要承诺文字或 `--sref` 能百分百锁脸。用户要锁脸或编辑时再查当前官方支持的功能。

## 图片阶段交付格式

直接给 N 条“中文短标题＋独立英文代码块”；每条代码块只有可复制提示词和必要参数。默认不附中文逐句翻译、长篇推导或额外版本。用户说“只要提示词”时连分析也省略。

用户同时要求风格分析时，在提示词前给一段判断和简短表格，区分可见事实、审美概括与创作选择。分析不取代提示词交付。

参考 [references/examples.md](references/examples.md) 学习不同题材、不同构图和精简输出的写法；只在需要示例时读取，不照搬整组内容。

## 成图后的约 4 秒动态规则

进入视频阶段时读取 [references/image-to-video.md](references/image-to-video.md)。以用户上传的实际成图为首帧依据，从已有姿态、道具接触和场景空间中延续动作；成图与之前文字设计不一致时，以成图为准，不补回图片里没有的人物或物件。

默认每张图输出一个约 4 秒的连续镜头，包含 **一种主要运镜或固定机位＋一个主要动作＋少量有因果的环境运动**。参考视频的平稳横移、舟中回望、轻盈行走、衣袖随风、水波与薄雾变化；具体选取服从当前图片。巨物的缓动表现体量，人物和衣料的运动表现生活感。

守住面部、发型、服装、人数、植物结构、建筑透视、主色与原有光向；让水纹、衣料和阴影随运动自然变化。不要把静态图片的坐姿跳成站姿、把已盛开的花再写成从花苞绽放，也不要默认为无鸟的图片增加鸟群。

视频提示词默认用中文自然语言，标题为“图片 01｜约 4 秒动态提示词”，每个独立代码块可直接复制。内容顺序为：首帧与画幅承接 → 镜头路径 → 主体动作 → 环境联动 → 稳定约束。通常约 150–300 个汉字即可，复杂动作按需要展开。默认连续自然运动，不切镜、不转场、不黑场收尾、不硬冻结末帧；用户另有要求时调整。

MJV8 只指定图片阶段。视频模型未指定时，默认按 Seedance 2.5 兼容的中文图生视频提示词习惯组织，时长写为“约4秒”；不加入 `--v`、`--ar`、`--raw`、`--s`、`--sref` 等图片参数，也不虚构通用 `--duration`。用户指定其他视频模型后，再按该模型已核实的输入方式适配。没有实际成图时，不声称完成基于成图的精确动态设计；可根据现有描述预写，并标明上传成图后校正。

## 发出前自检与修正

- 是否进入了正确阶段？图片数量、画幅、人物设定是否符合用户要求？动态提示词是否与实际图片逐张对应、约 4 秒，且每条可单独复制？
- 奇观有没有实际尺度证据？人物与舟、叶、地面有承托和接触关系吗？
- 主色、自然照明、材料的透光／反光是否协调？有没有把深绿阴影全部抹成白雾？
- 图片系列是否有构图和活动变化，同时保持风格与指定人物一致？视频阶段是否逐张遵守成图构图，不为追求变化擅自改景别或人物？
- 是否误加现代物品、夸张仙术、霓虹、游戏 CG、重妆塑料脸、截图水印？若是用户主动要求的则保留。
- 参数是否真实可用，参考图链接是否有效？没有实际生成时不要说“实测还原”或“已出图”。
- 视频动作是否从首帧已存在的姿态开始？人物、镜头、道具与风向是否协调？是否误用了图片参数、复刻黑场、添加无依据的新主体，或把单图扩成多场景？

用户反馈“不像参考”时先定位可见差异，再给修正版：比例不够就强化人与植物／建筑的对比；塑料感就调整材质与光线；太灰就恢复青绿、天青和暖肤色；太花就减少次要奇观；太空泛就补一个生活动作。不要只重复增加“电影级、超真实、震撼”。

# 不同题材与构图的图片范例 · 修复版

来源记录（下列为完整资料库内路径，仅供溯源，不是本包运行依赖）：原包主文（归档路径：`Skill解压/07-中式诗意巨物美学SKILL/中式诗意巨物美学SKILL.md`）；已归档教程（归档路径：`教程/07-中式巨物美学风格SKILL/教程.md`）。

以下六条是依据原主文新写的提示词范例，未跑图，不是作者原提示词或找回的九图逐张说明。叶面生活关系参考本次实看的005截图；木舟、古镇、茶席、紫藤与花前人像为主文允许的新设计。参数选择另见同目录 `mj-parameters.md`，用户设置优先。

## 先换关系，再换装饰

一组图要在机位、人物活动和尺度证据上变化，不只是把花从粉色改成白色。每条保留一种主要奇观、一个主要活动，并独立说明构图、光色与材质。

## 按反馈修正

- “巨物不明显”：补正常物体的尺度关系，例如叶冠遮住几座瓦房；不只继续增加giant。

# 巨物生活场景到约4秒视频 · 修复版

来源记录（下列为完整资料库内路径，仅供溯源，不是本包运行依赖）：原包主文（归档路径：`Skill解压/07-中式诗意巨物美学SKILL/中式诗意巨物美学SKILL.md`）；已归档教程（归档路径：`教程/07-中式巨物美学风格SKILL/教程.md`）。

依据主文“成图后的约4秒动态规则”和教程第三步文字重建。已看005四格图片与008视频页面静帧，未观看视频；下面的动作时间安排均是本次新设计。截图含界面和多格内容时，应由用户指定或提供其中单幅干净成图，不能直接假定整个截图就是首帧。

## 进入这个分支的条件

用户已经提供实际成图，或明确要求基于现有成图制作动态。没有图时，可以据文字预写，但标注“待成图校正”；不声称已完成逐图分析。多图逐张对应，不把六张图自动拼成一个24秒片段。

主文默认约4秒；教程说明中出现过“5秒”，所附示范文字又写约4秒。修复版不替作者消除这个历史差异：用户明确指定时服从用户；没有指定时采用主文约4秒，不推断平台必须支持某一时长。

## 首帧状态表

依实际图确认下面内容，再写动作：

| 字段 | 需要确认的可见关系 |
| --- | --- |
| 人数与身份 | 每人衣色、发型、面向、眼睛开合，不把四格中的同一人当四个人 |
| 支撑 | 谁坐在叶面、舟上、凳上或地面；身体重量落在哪个面 |
| 双手与物件 | 谁持竿、谁持扇；能否看清握点；鱼或钓线是否真的存在 |
| 主体当前阶段 | 鱼在水里还是已跃起；船静止还是有明显划水姿态；花已开还是花苞 |
| 遮挡与前景 | 鱼、叶缘、船舷、花瓣遮住了谁，不以运镜强行补出被遮住的完整身体 |
| 空间与画幅 | 地平线、叶面高差、岸线、可移动范围、原画幅 |
| 光与风 | 阳光来自哪边、反射落在哪边，衣缘和水纹是否提供一致风向线索 |

不能确认的内容用较小动作绕开。比如钓线不可辨认，就不要新增“绷紧的钓线始终牵着鱼”；手被遮住时，优先保留姿态并写目光或呼吸。

## 写一个能承接的连续镜头

按“首帧承接 → 一个主要运镜或固定 → 一个主动作 → 一两种环境反馈 → 稳定项”组织。动作在已有姿态里延伸；大植物采用轻缓形变或叶缘摆动，不像轻纸片高速翻卷。人物不能同时站起、换手、转身、跨舟又回望。

时间设计可用0–1秒建立轻微启动、1–3秒完成主要变化、3–4秒自然延续余动。它是新编节奏建议，不是对教程视频的逐秒测量；最终交付可以写成连贯段落，不必机械分三段。

## 新编范例A｜荷叶上静坐钓鱼

仅用于输入单幅成图中有两人、一人持竿、另一人持扇，且没有清楚的跃鱼轨迹时。主动作是持竿者轻收手腕，不替截图补造鱼的完整轨迹。

```text
约4秒单个连续镜头，继承输入图画幅、低水面仰视构图与两名女子在荷叶上的坐姿。摄影机固定。持竿者维持首帧握点，只轻轻收紧手腕，目光朝向图中已有的水面方向；持扇者继续保持原姿态，出现自然呼吸，不换手或站起。薄袖随同一阵风轻摆，叶缘缓慢起伏，水面细小涟漪沿原有空间向外扩散。保留两人的脸型、衣色、竿与扇归属、叶片承托、天空和光向；首帧没有的鱼、钓线或同伴都不新增，不切镜、不转场、不黑场收尾。
```

## 新编范例B｜已经在空中的鱼

仅用于实际首帧中鱼体已在半空、落水方向有足够空间且不与人物冲突的单幅成图。若方向无法确认，先改成更小幅鱼身摆动，不补完整起跳史。

```text
约4秒连续固定镜头，保留首帧人物、叶面、鱼与水面的前后关系。图中已经离开水面的鱼从当前姿态沿前方空余水面缓慢下落，鱼身轻摆，原有水滴受重力落回水面；不重新从水下起跳。鱼接近水面时只形成与其体量相称的局部水花和扩散涟漪，不覆盖两张脸。人物维持原来的坐姿、持竿与持扇关系，仅顺势出现细小反应；叶缘和衣袖轻动，强光方向不变。鱼、人物和道具数量稳定，镜头不环绕，不增加第二条鱼，不以闪白或黑场遮住结果。
```

## 新编范例C｜叶冠下的木舟

仅为主文允许的“撑舟、回望”题材新写；当前已看截图没有这艘舟，不能说它来自截图。实际图须已有舟、舟中人物与可辨认的水道。

```text
约4秒单个连续镜头，保持输入图画幅和舟中人物原姿态。摄影机在原水面高度缓慢横移一小段，木舟沿当前朝向轻缓前行，不突然转弯。人物只把目光移向原图已有的岸边，手与既有船舷或船桨保持原接触；看不到船桨时不补划桨动作。舟身带出细小连续水纹，近处叶缘相对远方瓦房产生轻微视差，巨叶冠层只作缓慢摆动。保持正常人体比例、舟形、建筑透视、叶柄来源和共同光向，不穿过叶柄或岸壁，不新增乘客、飞鸟、转场与字幕。
```

## 出现问题先减什么

- 手和道具漂移：减少换握与大幅肢体动作，保持首帧接触；不要继续叠加“绝对稳定”等空词。
- 叶面像塑料布：减少翻折幅度，保留厚边、叶脉与承托关系；不能靠视频动作挽救首帧本身缺乏支撑的设计。
- 镜头绕出不存在的空间：改成固定或轻微平移，不把单张成图强行扩成大环绕。
- 画面太忙：鱼、人物、机位只让一项承担主变化，其余保留从属反应。

## 从主文提炼的可迁移关系

1. **自然成为空间。** 荷叶可以是平台，植物冠层可以是天幕。先指定承托面或遮盖范围，再用正常大小的人、舟、桥、瓦房说明尺度，避免只写“巨大的”。
2. **人物在生活。** 选垂钓、乘凉、喝茶、撑舟中的一个主活动。人物坐在哪里、手接触什么、器皿由什么承托，要比“仙气飘飘”更明确。
3. **尺度奇幻，材质可信。** 叶柄仍从水里生长，叶面有厚薄与脉络；布料有重量、皮肤有自然细节，人物和植物共享光向与接触阴影。
4. **颜色有主次。** 主文以青绿、天青和水蓝组织环境，用米白、藕粉、浅杏作人物或花瓣点色；迁移秋景时可换成金黄，但不丢掉自然照明与空间层次。
5. **为画面留停顿。** 大片天空、平缓水面或一片叶面可以承接强烈前景。每张不要同时塞巨花、巨鱼、飞鸟、烟雾与多组人物。

以上是文字规则的重新整理，不是新增的已验证生图配方。

## 有实际新图时怎样补分析

先写可见事实，再写解释，最后写新增设计。例如“叶面横跨两个人的坐姿范围”是观察；“以叶面作为生活平台”是解释；“下一张让两人坐在竹台上”是新增设计。没有看到的背面、支撑点、型号、动作过程都留空，不用熟悉本风格代替看图。

当用户要求回到九张原图逐一复刻时，说明该批原图尚未找回，并继续处理实际提供的图。可使用本页与 `examples.md` 做新创作，不能把替代案例重新命名为原九图。
