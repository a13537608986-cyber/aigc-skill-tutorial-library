# 东方宫阙贵族人像 · MJV8.2

## 默认执行

1. 先判断任务：纯文字同款创作读 `references/style-guide.md`；逐图倒推读 `references/reference-guide.md` 并实际查看每张图；成图修复再读 `references/repair-guide.md`。用户最新要求优先于默认。
2. 用户只说“来一条同款”时，直接给已认可基准。用户只改场景时，保留当前已认可的人物原文，仅换场景句；不要重置成默认人物。
3. 默认输出一条英文提示词，正文70—90词、参数另计。中文说明最多一两句，英文放独立代码块；不附长篇拆解、翻译或重复负面列表。用户要求更短时优先删重复修饰，保留辨识特征和空间关系。
4. 按用户指定数量输出；多张参考按上传顺序逐张写，每条完整可复制，配简短中文名，不用“同上”。纯文字同款系列保持人物设定；不同参考图各自保留人物与服装差异。
5. 将连续反馈用于后续任务：“还有这几张”继承本轮无文字水印黑边、短提示词和仙境增强要求。若用户改为忠实还原原场景，则停止添加原图没有的幻想元素。
6. 输出前检查成人身份、逐图对应、景别与发型服饰是否符合当前任务、皮肤和织物质感、仙境空间、字数和参数。只对默认腰上创作检查完整冠顶与腰线；脸部特写不强塞腰线或全冠。

## 逐图还原与仙境增强

- 倒推时保留每图的景别、脸部朝向、髻型体积、垂发、饰物规模、衣领结构、手势及主辅色，不统一套用凤凰冠、无碎发、浅色袍或腰上构图。用户对当前图片明确提出的更改优先。
- 先区分“图中可见”与“新增创作”。参考图无法读取时尝试可用附件路径；仍不可读就说明并请重传，不凭旧记录声称看过新图。纯文字任务不强求参考图。
- 场景更仙时，用具体空间关系：悬宫浮在云海上、玉桥跨越云谷连接宫阙、瀑布由悬空玉台垂入雾海。每条选一组核心关系，加一层青绿远山；不要只加ethereal/dreamlike标签或罗列全部元素。
- 让近处栏杆、宫檐或池沿建立人物立足点；中景的中式飞檐与云桥可辨，远景逐层缩小变淡。人像保持主体，浅景深不把仙境全部抹成色块；面部特写只保留少量可读轮廓，不要求完整宏大建筑。
- 保留原图的亮暗组织：明亮飘花图保持浅青通透，深青宫阙图保留两侧暗建筑与中央亮雾；脸部柔和、中性微暖，金饰局部微亮，不统一染黄或加重整脸油光。
- 将 `references/reference-guide.md` 的近期提示词作为可复用草案，不能把未收到成图反馈的草案声称为实测成功或精确复刻。

## 纯文字同款创作的默认视觉基准

- **人物**：单个年轻成年中国宫廷贵族舞姬，安静、柔美、高贵、神秘；柔和鹅蛋脸、温柔深色眼睛、微张玫瑰色唇。自然眼白比例，不额外写深眼窝、尖下巴、冷硬妃嫔气质或夸张大眼。
- **皮肤**：白皙浅象牙色、细微毛孔、轻薄粉妆与自然血色。保持真实柔和的皮肤起伏，避免整脸油亮、蜡面、过度磨皮或刻意粗糙。
- **头发与饰物**：乌黑整洁圆润盘髻，有柔和体积和梳理纹理；无碎发、无垂脸发束。镂空金质凤凰冠、牡丹花簪、翡翠与珍珠流苏，金丝和珠串清楚；不默认加高冠体或改成厚重金筒。
- **服装**：裸露肩线与锁骨，象牙色丝绸在肩线下包裹，胸部有完整衣料遮盖与贴合绣纹，细金线牡丹刺绣、自然褶皱垂坠。默认浅色华服；不要自行回退到红金高领重袍、西式泡袖婚纱、盔甲或乳胶。
- **姿态**：默认一手自然停在锁骨附近、手指松弛。可在用户要求变化时轻转上身或让手低位拢袖，不默认高举大片丝布、不复杂交叠手指。
- **构图**：16:9满幅，腰部以上中景，完整冠顶与腰线入画，眼平视角，头顶适量余量，面部清晰。人物是主体，不因仙境宏大而改成远景小人；不强制偏右、侧视或留大块空白。
- **摄影与光色**：以85mm人像摄影语言、广而柔的自然日光、受控高光为默认。皮肤与丝绸中性微暖，远景青蓝和青绿，金饰局部细亮。浅景深主要用于少量前景和远景，宫阙轮廓仍可辨；不默认强烈暖黄夕照、深黑半脸或固定伦勃朗三角光。
- **仙境**：近处汉白玉或玉石露台提供人物立足点；中层云海、悬空中式宫阙与桥廊；远处青绿仙山和飞瀑，逐层淡入蓝雾。飞檐、层叠屋顶等中式建筑轮廓应可读。少量虚化花枝花瓣放边角；避免普通近处屋顶填满背景、纯色墙面、全白雾或过度虚化色块。
- **整体**：东方幻想电影人像，真实皮肤和织物支持幻想环境；不扩成卡通、游戏CG、油画或发光特效展示。无文案、文字、标志、水印、界面、黑边、粗相框和厚重暗角。

## 变化边界

- 以用户在2026-10-06最后认可的仙境版本为默认，不再把更早失败版本作为可选默认。
- 场景变化依照基准的空间顺序，替换具体地点与远景，不堆叠所有仙境元素。使用 `references/style-guide.md` 中的短场景句起步。
- 纯文字同款系列默认是同一人物设定；逐图倒推不适用本条。保持原有五官、髻型、冠饰体系、衣服主色与用光文字。用户明确要求换角色或服装时才调整；文字一致不等于模型能精确锁脸。
- 用户明确要求其他年龄、人物、光线、色彩、数量、比例或语言时优先执行，不让默认覆盖新指令。
- 不自行加入视频、镜头时间轴、长篇人物小传或生图任务。用户要求生成图片时才调用相应工具，并说明实际可用的模型，不把其他生图工具的输出声称为MJ结果。

## 参数与真实性

- 通用末尾为 `--ar 16:9 --v 8.2 --raw --no text watermark logo borders letterboxing`。仅在默认整洁盘发创作或用户明确要求无碎发时追加 `flyaways`；还原垂发和面侧发丝时不加。用户指定比例优先；所有参数放正文后。
- 不默认添加额外风格化或参考权重。纯文字可以创作相近方向，不要求每次上传原图；不承诺完全复刻特定面孔、必然正常五指或完全无水印。
- 不编造参考图URL、风格代码、种子或测试结果；不要把风格参考描述成锁脸工具。
- 当前V8.2不使用 `--q`、`--oref`、`--ow`、`--cref`、`--cw` 或多提示权重 `::`。涉及新参数或版本变化时查官方文档。
- 已核验来源（2026-10）：https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version 、https://docs.midjourney.com/hc/en-us/articles/32634113811853-Raw 、https://docs.midjourney.com/hc/en-us/articles/32173351982093-No 。
- 区分用户认可的创作方案与已经亲自验证的模型结果。没有实际生成和查看，就不宣称测试出图成功；85mm等为创作方案，不是从参考图鉴定出的真实器材。

# 逐图倒推与仙境场景草案

# 成图诊断与已知偏差

仅在用户说“不像、油腻、没美感、场景不对”或要求分析新参考时读取。正常创作以style-guide.md的已认可版本为默认，不把失败方案再次拼进提示词。

## 诊断流程

1. 实际查看当前成图和可用参考。文件不可读先尝试当前附件路径；仍不可读时明确说明，不假装看过。
2. 提取可见的气质、成年年龄感觉、五官比例、发型体积、冠体形状、服装结构质感、景别、空间、主辅色、光源颜色与明暗。将实际观察与拟采用的摄影参数分开。
3. 用户认可的部分直接保留，只指出本轮相关的2—4个差异；不每次重做全部风格分析。
4. 把可能的提示词影响表述为推测，没有受控测试不声称某词就是唯一原因。只有重复出现无法解释的偏差时，再请用户提供实际提交的提示词、模型参数与参考设置，不把问题预先归咎平台。
5. 给一条精简完整修正版，说明本轮修改重点。新版本仍需成图确认，不使用“保证复刻”“已解决全部问题”。

## 原始参考的区别

- 飘花近景（文件名含20.39.49）：脸占比大，浅青蓝宫阙、白雾和粉花瓣，皮肤有薄粉妆与细微质感，发缘有暖光。原图是胸上近景，不把此裁切带入腰上默认。
- 象牙袍正面（含20.39.43）：人物居中，丝袍斜向交叠；两侧暗宫殿、中央冷青远雾、石栏后退、边缘金叶。不要机械改成偏右站位或大留白。
- 红牡丹凤凰冠（含20.39.13）：暗红牡丹与宽展金丝冠、红金绣锦内层和象牙外袍；深青背景衬柔亮脸。原参考的红金方向不等于当前已认可的浅色衣服默认。

这些是此前实际看图记录，不是正在查看原图的声明。无文字水印黑边始终沿用。逐图还原应保留参考的垂发或面侧发丝，除非用户对当前任务明确要求无碎发；不得将旧的默认盘发设定覆盖新参考。

## 常见偏差与修法

| 可见偏差 | 优先修正 |
| --- | --- |
| 油腻或假皮肤 | 区分大面积反光、肤色染黄、过度磨皮和过锐；保留细微毛孔、自然血色与薄粉妆，不改成纯白无光面具 |
| 成熟冷硬、锐利眼神 | 回到柔和鹅蛋脸、温柔深色眼睛、微张玫瑰唇，减弱深眼窝和强阴影描述 |
