# 成图诊断与已知偏差

仅在用户说“不像、油腻、没美感、场景不对”或要求分析新参考时读取。正常创作以style-guide.md的已认可版本为默认，不把失败方案再次拼进提示词。

## 诊断流程

1. 实际查看当前成图和可用参考。文件不可读先尝试当前附件路径；仍不可读时明确说明，不假装看过。
2. 提取可见的气质、成年年龄感觉、五官比例、发型体积、冠体形状、服装结构质感、景别、空间、主辅色、光源颜色与明暗。将实际观察与拟采用的摄影参数分开。
3. 用户认可的部分直接保留，只指出本轮相关的2—4个差异；不每次重做全部风格分析。
4. 把可能的提示词影响表述为推测，没有受控测试不声称某词就是唯一原因。只有重复出现无法解释的偏差时，再请用户提供实际提交的提示词、模型参数与参考设置，不把问题预先归咎平台。
5. 给一条精简完整修正版，说明本轮修改重点。新版本仍需成图确认，不使用“保证复刻”“已解决全部问题”。

## 常见偏差与修法

| 可见偏差 | 优先修正 |
| --- | --- |
| 油腻或假皮肤 | 区分大面积反光、肤色染黄、过度磨皮和过锐；保留细微毛孔、自然血色与薄粉妆，不改成纯白无光面具 |
| 成熟冷硬、锐利眼神 | 回到柔和鹅蛋脸、温柔深色眼睛、微张玫瑰唇，减弱深眼窝和强阴影描述 |
| 高领重袍或西式礼服 | 明确裸露肩线锁骨、肩线下包裹的象牙丝绸、细金牡丹刺绣；避免大面积红金与笼统gown/bodice叠加 |
| 举布摆拍 | 删除lifting silk等高举暗示，回到一手松置锁骨附近；不增加复杂交叠或强行露全五指 |
| 冠体过高、糊成金筒 | 保留镂空凤凰金丝与分离珠串，减少纵向堆叠，明确完整冠顶和适量头顶余量 |
| 普通宫殿、没有仙境 | 保持人物原文；选一组悬宫浮在云海、玉桥跨云谷连接宫阙或池沿飞瀑垂入雾海的关系，再加远山雾层；不要只堆仙境形容词 |
| 场景糊成色块 | 保留飞檐、桥廊等可辨轮廓，近实远淡；不过度浅景深，也不把主体缩成小人物 |
| 黑边、文字水印 | 保持16:9满幅与简短排除参数，不照抄参考文字，不加遮幅词 |

已发生的失败提醒：偏右站位、向画外侧视、暖逆光和裸枝的组合曾偏离参考；大红金织锦与高举丝布曾变成厚重宫装展示。记录只用于避免重复试错，不证明单词的普遍因果。

当前基准来自后续被认可的浅色露肩人物；用户只要场景更仙时，不能再回退到上述失败人像方案。
