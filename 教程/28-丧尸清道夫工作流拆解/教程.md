# 第二节：视频提示词


![image.png](../../%E8%B5%84%E6%BA%90/28-%E4%B8%A7%E5%B0%B8%E6%B8%85%E9%81%93%E5%A4%AB%E5%B7%A5%E4%BD%9C%E6%B5%81%E6%8B%86%E8%A7%A3/007-image.png)


```text

一、基础设定
机器人清道夫：身形修长的人形机器人，1960 年代原子朋克风格设计。拥有自主意识。面部 led 显示屏代替五官，显示马赛克像素风格的表情（表情无动态效果，保持静帧显示）。身穿美式西部牛仔复古风格的棕棕色牛仔帽、黑色哑光高腰设计皮衣夹克、黑色哑光皮手套、牛仔腰带和枪套。

非洲鸵鸟：成年非洲鸵鸟，样貌看起来呆傻，双眼歪斜不对称，歪吐着舌头。

丧尸：多只腐烂惊悚的丧尸，头发凌乱，皮肤溃烂，肤色灰白暗沉，布满破损伤口与污痕，眼球浑浊发白、瞳孔无光，露出尖锐泛黄的腐烂獠牙，表情狰狞；身着破烂不堪的海滩度假风和日常休闲装，皮肤与衣物沾满血渍与腐败肌理。

场景：1960 年代美式复古原子朋克城市街道，刚刚爆发丧尸危机、大战过后的城市，历过一场战斗的死寂。盛夏烈日当空，复古未来主义，复古乌托邦，冷战太空流线型建筑，混乱场景，破损报废的复古老爷车，散落的报纸，地面有血渍，60 年代临街商铺，圆穹顶科幻楼宇。场景四处均有丧尸的尸体。休闲的惬意的环境与丧尸的尸体形成极大的反差对比。

声音：不需要配乐，仅保留同期声。

二、氛围与画质
风格核心：原子朋克、末日丧尸、电影级质感、超写实、极致逼真、真人实景拍摄、杜绝游戏 CG 感、杜绝动作僵硬。原本闲适的场景与恐怖丧尸形成强烈荒诞反差。
保持速度，整体氛围幽默且滑稽。
视觉基调：变形宽荧幕电影质感。使用 IMAX 胶片摄影机，搭配 Panavision C 系列镜头（添加动态模糊）拍摄。
色彩与影调：60 年代复古科幻原子朋克美学，复古暖橙 + 海蓝高对比色调，胶片颗粒质感，低饱和度复古胶片滤镜，采用自然日光照明；整体光线通透均匀，高光不过曝，暗部保留完整细节，明暗过渡自然，营造通透明亮的光影氛围，带轻微复古胶片柔光质感。

三、画面内容
分镜一：00:00-00:07
景别：电影感，史诗级大全景。
构图：无人机高空俯拍，利用公路作引导线构图。
运镜手法：主体入画后跟随，固定机位镜头缓缓上摇。
画面内容：机器人骑着鸵鸟飞驰在公路上，背对镜头从画面下方入画，位于街道中央，沿着笔直的公路狂奔。街道上散落着触目惊心的尸体和血迹。机器人左手握住鸵鸟脖子，右手按压住自己的牛仔帽防止掉落，骑乘在鸵鸟的背上。鸵鸟高速奔跑，翅膀微张，双脚交替蹬踏地面，在街道上蛇形走位高速奔跑，带有动态模糊感。在其身后的远处，出现一片行动缓慢丧尸尸潮，尸潮背对镜头，从画面下方入画。丧尸们嘶吼声此起彼伏，移动速率前后不一，尾随在鸵鸟后方。渲染末日危机氛围。

分镜二：00:07-00:10
景别：轻微仰拍，机器人上半身近景。拍摄正面 30 度。
构图：人物与鸵鸟处于画面中心作为前景，街道建筑为背景。运镜手法：固定机位，运动跟随拍摄主体。
画面内容：鸵鸟奔跑产生剧烈抖动，持续高频颠簸、震颤，随着步伐上下晃动；机器人身体随鸵鸟步伐产生高频的剧烈颠动、前倾后仰、腰身颠簸而不受控的起伏，坐姿随颠簸猛烈晃动，导致机器人的身体跟随鸵鸟奔跑起伏的频率而猛烈颠簸。机器人面部 led 屏幕保持蓝色冷酷表情，很是无奈，身体颠簸的同时发出生无可恋的颤音（电子机械感，人工智能男性音色）。与上个镜头画面产生反差，整体滑稽，渲染搞笑氛围。

分镜三：00:10-00:15
景别：俯拍地面报纸特写。
构图：报纸位于画面中央，占据画面大部分面积。对角线构图。
运镜手法：固定机位，开始拍摄报纸（特写），鸵鸟脚掌入画后摇镜头跟随。主体变更，画面由特写变为全景。
画面内容：地面一张充满褶皱与少量血渍的破旧英文报纸，报纸头条标题写着：ZOMBIE VIRUS OUTBREAK，副标题：Coastal cities fell into enemy hands，并配有配图。报纸静静的待在地面，被闯入画面的鸵鸟脚掌踩一脚后，报纸黏在脚掌皮带。随后摇镜头拍摄机器人骑鸵鸟离去的背影（变为全景），鸵鸟脚上粘住了报纸使其很不舒服，没跑多远就改变奔跑模式，变为单脚跳跃前进，另一只脚抬起试图甩开粘在脚上的报纸。整体氛围诙谐幽默。
```
