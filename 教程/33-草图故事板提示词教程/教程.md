# 火柴人草图故事板提示词：


![草图故事板.png](../../%E8%B5%84%E6%BA%90/33-%E8%8D%89%E5%9B%BE%E6%95%85%E4%BA%8B%E6%9D%BF%E6%8F%90%E7%A4%BA%E8%AF%8D%E6%95%99%E7%A8%8B/003-%E8%8D%89%E5%9B%BE%E6%95%85%E4%BA%8B%E6%9D%BF.png)


```markdown
使用极其简单的二维预览草图风格：
仅限简笔画人物/人体模型轮廓
- 没有面部细节，没有服装细节，没有解剖细节
- 没有纹理，没有阴影，没有精细渲染
黑色的粗略素描线条
- 红色方框仅用于相机取景
- 蓝色箭头仅表示运动/力量/呼吸/方向
- 导演的粗略草图，不是概念图
如果不确定，就少画一些细节，而不是多画一些。
在一页上显示 8 个编号的面板，位置略有不规则但清晰易读。
主题：两个好朋友踩着滑板在云层之上竞速
环境：晴朗的开阔天空，蓬松的云朵，漂浮的云层，远处的阳光，然后是较暗的暴风云区，伴有风、雨和闪电。
情绪：轻松、冒险、节奏快、有趣，短暂地有些悬疑，然后令人振奋和充满胜利感
剧情：在一场有趣的云朵滑板比赛中，一个朋友不小心滑进了危险的风暴云中，失去了控制，另一个朋友在最后一刻救了他。
节拍：
1. 广角镜头。两个朋友踩着滑板在云端之上并肩滑行，在天空中嬉戏玩耍。
2. 侧向镜头。比赛速度加快。一位朋友向前倾身，稍稍领先，另一位紧随其后。
3. 前四分之三角度。领头的车友在专注于比赛的同时，不小心驶向了前方一片乌云密布的区域。
4. 俯拍镜头。暴风云吞噬了领头的朋友。狂风呼啸，暴雨闪电交加。滑板剧烈摇晃。
5. 特写/中景动作镜头。第二个朋友注意到危险，猛踩刹车一瞬间，然后转身冲向风暴。
6. 动态低角度镜头。救援人员踩着滑板冲进暴风云，冒着狂风和闪电，向前伸出手臂，去营救被困的朋友。
7. 英雄侧影。千钧一发之际的救援。救援者抓住同伴的手臂或连帽衫，将他们从暴风云中拉出来，就在闪电击中他们身后的一刹那。
8. 远景镜头。两位朋友突然冲进阳光灿烂的云层中，重新站稳，继续并肩骑行，笑着继续比赛。
使用不同的拍摄角度：特写、广角、低角度、俯视、侧面、背面、四分之三视角。
在展板附近添加简短的手写注释。
保持主体、道具、环境和动作方向的清晰连贯性。
重点关注场景布置、镜头运用、动作控制、节奏把控和连贯性。
优先考虑可读性而非绘图质量。
避免使用细节丰富的插图、简洁的用户界面和信息图表设计。
基调目标：充满乐趣的家庭动画活力，清晰的视觉叙事，简单易懂的动作节奏，适用于 15 秒的动画序列。16:9
```








# 视频生成提示词：


```text
意图：创造一个充满乐趣、活力四射的友谊冒险故事，其中一名骑手被卷入暴风云中，场面一度紧张，但最终以一次成功的营救和快乐的归来而告终。
风格：风格化的末日废墟特色 3D 动画感觉，圆润富有表现力的轮廓，清晰易读的造型，柔和多云的氛围，明亮的蓝天过渡到充满张力的风暴灰，令人振奋的精致饰面。
世界：一片高耸入云的云海，滑板般的板面在蓬松的云层间滑行，阳光普照，而危险的风暴中心则充满了风、雨和闪电，仿佛生机勃勃。

参考：
使用提供的预览故事板页面 @ {{Mixed 2}} 作为主要参考。
不要将页面视为单个图像。
将分镜视为连续镜头的关键帧，并将它们扩展成一个连贯的短场景，使其具有清晰的连续性。
使用 {{Portrait 1}} 作为角色参考。

视觉方法：
与故事板的空间多样性和情感节奏保持一致。
优先考虑可读性、屏幕方向和动作的连贯性。
保持视觉运动平静、有条理，而不是躁动不安。
```
