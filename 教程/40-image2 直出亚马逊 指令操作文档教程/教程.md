# 一、这个方法适合做什么？

这套方法适合用 image2 快速生成亚马逊 A+ 页面图、产品卖点图、使用场景图、功能拆解图、对比图和详情页视觉方案。

核心不是让 AI 随便画，而是用“产品识别报告”先把信息结构搭起来，再把报告转成每一屏的生图提示词。

- 适合做：数码产品、家居用品、户外装备、美妆个护、小家电、宠物用品等。

- 最适合的场景：快速提案、A+ 视觉方向测试、详情页初稿、跨境电商产品图延展。

- 不适合直接吹成最终交付：文字、参数、产品比例和品牌规范仍然需要人工检查。


# 二、开始前需要准备什么？

- 产品图片：主图、多角度图、包装图、细节图、真实使用场景图。

- 产品基础信息：产品名称、品牌名、类目、参数、适用人群、使用场景。

- A+ 类型：普通 A+、高级 A+、移动端 A+、Web 端 A+、5 屏 / 6 屏 / 7 屏。

- 目标市场：美国、英国、日本、德国等，不同市场审美和用语要分开。

- 目标风格：欧美极简科技风、黑金高端风、白灰苹果风、户外硬核风、家居生活风等。


# 三、标准工作流


|  |  |  |
| --- | --- | --- |
| 步骤 | 动作 | 目的 |
| 1 | 先识别产品 | 让 AI 读懂产品，而不是直接出详情图。 |
| 2 | 再修正信息 | 产品参数不能靠 AI 瞎猜，必须人工确认。 |
| 3 | 规划整套 A+ | 先定每一屏讲什么，再让 image2 出图。 |
| 4 | 一屏一屏生成 | 不要一次生成完整长图，容易崩。 |
| 5 | 逐张检查修正 | 重点看文字、产品结构、参数、卖点是否准确。 |

 


# 四、第一步：产品信息智能识别

上传产品图后，先让 AI 输出结构化识别报告。


|  |
| --- |
| 产品信息识别提示词 |
| 请你作为一名专业跨境电商视觉策划和亚马逊 A+ 页面设计师，仔细分析我上传的产品图片，帮我提取产品信息。<br><br>请输出以下内容：<br>1. 产品名称判断<br>2. 产品所属类目<br>3. 产品外观特征<br>4. 产品核心参数<br>5. 产品功能卖点<br>6. 产品使用场景<br>7. 目标用户人群<br>8. 适合的视觉风格<br>9. 适合亚马逊 A+ 页面表达的卖点排序<br>10. 可能需要补充确认的信息<br><br>要求：<br>- 不要乱编不存在的参数<br>- 不确定的信息请标注“需确认”<br>- 输出结构清晰，方便后续生成 A+ 页面提示词 |

 


# 五、第二步：检查并修正识别报告

识别报告出来以后，一定要人工修正。AI 识别错了，后面的 A+ 图就会全部跟着错。


|  |
| --- |
| 识别报告修正提示词 |
| 请修正以上识别报告：<br><br>产品名称是：[填写产品名称]<br>产品容量是：[填写参数]<br>目标市场是：[填写国家]<br>产品核心卖点是：[填写卖点]<br>A+ 页面数量是：[填写屏数]<br><br>请基于我修正后的信息，重新整理一份准确的产品识别报告。<br>要求：不确定的信息继续标注“需确认”，不要虚构参数。 |

# 十、出图后检查标准

1. 产品有没有变形，结构是否真实。

2. 产品颜色、比例、接口、按键、屏幕等细节是否正确。

3. 文字有没有乱码、错字、英文拼写错误。

4. 卖点是否清楚，用户能不能一眼看懂。

5. 画面是否干净，有没有过多装饰和杂物。

6. 是否符合目标国家审美和亚马逊 A+ 页面阅读习惯。

7. 是否存在夸大宣传、虚假参数或不合规表述。

8. 整套图的色系、字体、光影和排版是否统一。
