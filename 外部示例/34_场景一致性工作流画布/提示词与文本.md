# 场景一致性


## 1 剧本拆解

完整镜头拆解 (Shot Breakdown)

&nbsp;

00:00.000 - 00:05.500

开场片段。 特写镜头显示一个浑身污泥的丧尸女孩踉跄走向泳池，随后镜头切换为远景，丧尸跳入泳池的瞬间被击中，伴随着巨大的水花和散落的钞票。阳光明媚，背景是现代风格的海滨豪宅。

&nbsp;

00:05.500 - 00:10.500

角色介绍。 中景低角度镜头。AI清道夫出现在镜头前，帅气地转动并平举他的多管银色左轮手枪。背景是热带植物和现代建筑。镜头平稳，展现出角色的冷静。

&nbsp;

00:10.500 - 00:16.000

标题序列。 航拍大远景，显示一座矗立在悬崖边的未来感豪宅，俯瞰着阳光下的海滩。屏幕上出现巨大的红色标题“ZOMBIE SCAVENGER”。镜头缓慢向前推，确立了地理位置。

&nbsp;

00:16.000 - 00:26.500

清道夫日常节拍。 剪辑组合。清道夫在泳池边像扔垃圾一样抛掷丧尸尸体；随后他随着复古音乐在尸体堆中跳舞。镜头角度多变，包含俯拍和手持感的跟拍，节奏欢快。

&nbsp;

00:26.500 - 00:37.000

环境巡视。 中景镜头。机器人悠闲地行走在满地狼藉的室内，阳光透过巨大的圆弧形落地窗洒下。他时而整理帽子，时而在尸体间旋转，展现出极端的乐观。镜头采用平缓的横向移动。

&nbsp;

00:37.000 - 00:51.500

喜剧转折。 机器人来到吧台前，显示屏变为伤心的黄色表情。镜头反转显示一只巨大的鸵鸟正在吧台上喝洒。机器人与鸵鸟对视，表情变为疑惑。特写镜头捕捉鸵鸟伸长舌头的滑稽样子。

&nbsp;

00:51.500 - 01:01.000

行动开始。 机器人骑在鸵鸟背上，撞碎巨大的玻璃幕墙飞跃而出。镜头采用快速的低角度跟拍，展现冲击力。背景是碧海蓝天和沙滩上的丧尸群。

&nbsp;

01:01.000 - 01:15.000

鸵鸟骑行序列。 一组动感十足的远景镜头。机器人驾驭鸵鸟在沙滩上飞驰，身后跟着一群追赶的丧尸。随后进入废弃的现代城市街道，两旁停满了60年代的经典轿车。摄像机伴随鸵鸟侧向移动。

&nbsp;

01:15.000 - 01:21.500

主观视角战斗。 近景手持镜头，紧贴机器人的背部。他一边驾驭鸵鸟，一边高举某种动力电池设备。镜头剧烈晃动，增加了紧张感和速度感。

&nbsp;

01:21.500 - 01:33.000

战斗蒙太奇。 快速剪辑的战斗画面。机器人跳下鸵鸟，在街道上使用格斗术和左轮手枪近距离处决丧尸。其面部表情变为红色的愤怒模式。镜头包含快速的推近和环绕运动。

&nbsp;

01:33.000 - 01:48.000

进入市区。 机器人在鸵鸟背上脱帽致意。镜头拉远显示整个荒废但阳光充足的街道。画面中出现“1969 U.S. WEST COAST”字样。鸵鸟在空旷的马路上狂奔。

&nbsp;

01:48.000 - 02:00.000

事故节拍。 远景镜头显示街道中心横卧着一棵巨大的棕榈树。机器人和鸵鸟避让不及撞了上去。特写显示机器人的帽子飞掉，他狼狈地在地面滑行，表情变为尴尬。

&nbsp;

02:00.000 - 02:09.500

恢复状态。 机器人捡起帽子，面部变为沮丧。他走到一家名为“Turt's”的时装店门口，推门而入。镜头平视，跟随着他的脚步进入昏暗的室内。

&nbsp;

02:09.500 - 02:20.500

核心偶遇。 机器人在店内看到一个聚光灯下的红色裙子假人。面部表情瞬间切换为粉色的爱心模式。镜头通过假人的肩后视角望向机器人，建立起两者之间的视觉关联。

&nbsp;

02:20.500 - 02:34.000

约会蒙太奇1。 快速场景切换。他们在快餐店并排坐着，背后是拍打窗户的丧尸；他们在阳光下合影，机器人拿着老式拍立得相机。镜头多为静态构图，类似老照片。

&nbsp;

02:34.000 - 02:49.500

约会蒙太奇2。 浪漫活动。在破旧的电影院并排坐着，机器人试图搂住假人的肩膀；在游戏机房，机器人砸碎玻璃为她拿取泰迪熊。镜头运动变得柔和且温情。

&nbsp;

02:49.500 - 03:00.000

生活片段。 他们一起坐过山车；在理发店并坐（即使中间隔着一个真丧尸）；最后在夕阳下的长椅上背对镜头并坐，机器人开枪射杀从侧面袭来的丧尸。构图平衡，极具美感。

&nbsp;

03:00.000 - 03:12.000

离去节拍。 夕阳西下，机器人带着假人走向楼顶的球形飞船。远景镜头展示了未来主义城市的轮廓。机器人登机前向地球告别。

&nbsp;

03:12.000 - 03:34.000

终章。 飞船升空飞向宇宙。特写显示机器人在船舱内亲吻假人的手。最后一个镜头是两人并坐在飞船窗前，望着远方的地球，飞船渐渐远去。屏幕出现“END”字样。
